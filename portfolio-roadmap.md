# Portfolio Roadmap

This roadmap keeps the portfolio focused, consistent, and easy to expand over time.

## Stage 1: Foundation

Create the repository identity, documentation standards, project template, and a clean folder structure. The first published project should demonstrate careful data preparation, clear visual communication, and practical conclusions.

## Stage 2: Core Analytics

Add one project in exploratory data analysis, one SQL project, and one dashboard project. Together, these projects should demonstrate the ability to move from raw data to business insight.

## Stage 3: Advanced Analysis

Add a project involving customer segmentation, forecasting, experimentation, or predictive modeling. The project should explain model assumptions and evaluation in accessible business language.

## Stage 4: Portfolio Refinement

Review project naming, screenshots, README quality, reproducibility instructions, and consistency of tools. Pin the strongest repositories on the GitHub profile and keep each project focused on a clear outcome.

## Suggested First Projects

| Priority | Project idea | Main skills |
|---:|---|---|
| 1 | Retail sales exploratory analysis | Python, Pandas, visualization, KPI analysis |
| 2 | Customer churn analysis | SQL, Python, segmentation, business recommendations |
| 3 | Executive sales dashboard | Power BI or Tableau, data modeling, storytelling |
| 4 | Marketing campaign performance | SQL, conversion metrics, cohort analysis |
| 5 | Demand forecasting | Time series, evaluation, interpretation |
